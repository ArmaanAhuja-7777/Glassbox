# Figma exports (reference images)

PNG exports (2x) of the Figma components and four full screens, made by the owner on 27 Oct 2026.

- **Reference only.** Since 29 Oct 2026, Figma is a visual reference reviewed by eye; nothing compares against these files automatically (decisions log). Automated visual tests compare against our own approved screenshots in `e2e/visual/__screenshots__/`.
- **Old colours.** The images show the muted palette, from before the Signal palette (28 Oct 2026). For colour values, the tokens in `packages/tokens/source` are the truth.
- **What's here:**
  - `button/`, `tag/` and `flow-node/` hold the Figma component variants.
  - `screens/` holds four full screens (02, 06, 17, 27).
  - `screens/crops.json` records where individual components sit in them, in Figma pixels.
